
This folder contains the code for a python program which uses a C function internally for capitalizing the string. On a high level, we allocate some memory in wasm runtime and copy the string to it and call the function which executes in wasm runtime. Once the function executes, we copy the contents back to our runtime and return it to stdout.

# Directory structure

### C and Cython
- capitalize.C => The capitalize function is implemented here.
- capitalize_wrapper.pyx => The cython code that internally calls the C functions.
- setup.py => The logic to cythonize the Cython code and create a .C and .so files from it.

### Sandbox Files
- wasm_bridge.py => The sandbox logic is implemented in this file which allocates memory in wasm runtime and copies the string to that runtime and calls the function instance from wasm bytecode.
- wasm_capitalize_wrapper.pyx => The updated Cython code which calls this wasm_bridge.py instead of calling the .C function directly.


### Generated files
- capitalize_wrapper.C => This is the new C code that is generated by cythonize command that takes the Cython code and converts it to a .C file.
- capitalize_wrapper.cpython-313-darwin.so => This is a shared object which is a dynamically compiled object from the cython code which uses this C code internally.
- capitalize.wasm => This file is generated by the wasm-sdk api that takes the C code and creates a wasm bytecode from it.
- wasm_capitalize_wrapper.c => The file generated from the wasm_capitalize Cython code.

# Key Concepts

.wasm file => portable, low-level byte code that can run safely on different platforms
Wasmtime => light-weight virtual machine that runs .wasm files outside the runtime memory of the process (OS)
Store => container that holds all the runtime state during the execution (Process - all stack, heap etc.)
Module => the wasm file gets converted to native machine code 
Instance => It is a live version of a module (more like an object of a class)

Store.engine => low level component in wasmtime which can convert wasm byte code to native code
instance.exports(store) => it gets all the exported items of the instance in the store which includes functions, memories, etc.

memory = instance.exports(store)['memory']
memory.data_ptr(store)				=> this is the memory view of the wasm runtime
